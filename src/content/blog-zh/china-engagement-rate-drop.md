*点赞在掉，发布量没变。用户没有走。整个2025年，中国主流平台逐一改写了“互动”的定义，而品牌侧的报表仍在按旧口径记账。平台机制变动频繁，本文每季度复核一次，最近一次核对为2026年7月。*

过去一年，微信、小红书、抖音、微博四个账号的互动量同时走低，数字本身没有出错，出错的是它衡量的对象。

去年，四家平台朝同一个方向拧了参数。点赞的成本是半秒钟，评论的成本是一句话，关注的成本则是一个判断：往后还愿不愿意听你说话。平台开始为有成本的动作付流量，对其余动作悄悄降权。

品牌那套中国数据看板，多数仍在给最廉价的动作打分。跌幅的源头就在这里。

## 先看结论

| 品牌还在考核的        | 平台在2026年真正计分的            |
| ------------------ | ----------------------------- |
| 单篇点赞数           | 评论顶4个赞，关注顶8个赞          |
| 首日触达             | 一条持续7到15天的爬坡曲线         |
| 粉丝数               | 搜索，占小红书流量的65%           |
| 微信打开率           | 转发，占内容健康度权重的20%        |
| 视频播放量           | 完播率，以及前三秒               |
| 在微博加大发布量      | 在热搜还活着的窗口里发            |

## 从微信看起：跌幅最早出现在这里

微信的打开率已经连跌数年，2025年没有出现拐点。

> 2025年第一季度，订阅号平均打开率为0.89%，服务号为1.32%，较上年同期低约0.2个百分点。
> 来源：壹伴，2025

不少品牌把它当成内容问题。更准确地说，这是管道问题：推送早已不是进入一篇微信文章的主入口。

> 某财经账号的数据显示，45.9%的流量来自社交推荐，首次超过订阅号推送。
> 来源：极致了数据，2025

承认这一点，那套计分逻辑才讲得通。下文若干数字出自杭州的监测机构极致了数据。我们拿这套机制去比对客户后台，方向吻合，只是具体百分比会随品类上下浮动一两个点。

> 微信对文章健康度的评估中，打开率占40%的权重，点赞、在看、收藏等互动占30%，转发率占20%，完读率占10%。
> 来源：极致了数据，2025

打开率仍是权重最高的单项，上限却被粉丝盘子锁死。仅此一条，就够推翻我们接手的多数微信方案：计分表里的其余部分，决定的是粉丝之外的人能不能看到这篇文章。靠加倍发文去抬打开率，等于门关着的时候去修天花板。

## 抖音把判决期拉长了

2025年，抖音动了一处设定，很多品牌的月度报表因此失真：平台不再在第一天就给一条视频定生死。

> 新视频先进入500到1000次曝光的冷启动池。完播率要达到40%才能进入下一层流量池，前三秒承担40%的留存权重。2025年的机制重构还把推送周期从大约24小时拉长为7到15天的爬坡，期间按每日互动数据动态调整推荐。
> 来源：极致了数据，2025

周报因此在赛程未完时合上卷宗。周二看着已经凉透的视频，下周一可能仍在测试。我们见过代理商第三天砍预算，把一条正在爬坡的视频掐断，再把它写进复盘，记作内容失败。

同一轮改版里还有两个数字，放在一起才看得懂：为什么四平八稳的企业片跑不过粗糙的片子。

> 2025年，硬广类内容的完播率同比下降37%。
> 来源：极致了数据，2025

算法如今把成交读成质量信号，而不只是生意结果。

> 转化率3%的视频，拿到的自然流量约为转化率1%视频的四倍。
> 来源：极致了数据，2025

在抖音，卖得好不发生在拿到流量之后，它本身就是拿流量的方式之一。若中国方案把生意和内容分作两笔预算，这个结论并不好受。

## 在小红书，点赞是最不值钱的那一项

最清楚的案例来自小红书：它的计分公开到你可以自己把账算一遍。

> 内容体验分中，一次关注计8分，一条评论或一次分享计4分，一个赞或一次收藏计1分。
> 来源：极致了数据，2025

拿两篇笔记算一遍。第一篇：九百个赞，五条短评，零新增关注，得分约920。

> 八个字以上、描述了具体情境的评论，权重约为短评论的三倍。收藏多但长期没有评论的笔记，可能被判定为低质并限流。目前小红书超过65%的流量来自搜索，而非信息流。
> 来源：极致了数据，2025

第二篇安静得多：两百五十个赞，四十五条写得具体的评论，三十个新关注，得分接近1030。点赞不到前者三分之一的笔记反而分数更高，平台也推得更用力。同一个品牌，同一笔预算。

既然点赞几乎不进计分，平台为何仍把数字挂在那里？因为它给你和其他用户看，是社交证明。计分是另一套系统，从来不为谁的截图服务。

点赞失效还有第二个原因：这个平台有三分之二不是信息流。

吃到搜索词的笔记能连着几个月往回倒流量，发布当天却几乎没有数据。按首日互动率判，它像一次失败；在我们审计过的多数账号里，它属于最值钱的那类资产。

> 小红书每天约有3900万用户表现出明确的购买意图，每天有1.4亿次用户主动寻找产品的行为。
> 来源：虎嗅，2026

## 越来越多品牌，在抢同一批八小时

连讲三套机制之后，这一段与机制无关。

跌幅里有一部分，纯属算术。

> 2025年全年，小红书以12.1%的日均使用时长增幅领先所有平台，抖音第二，视频号第三，微博下降2.1%。在用户黏性上，抖音的日活月活比达到76.3%，视频号为62.5%，小红书从2023年的32.4%升至39.1%。
> 来源：知乎，2025

注意力在应用之间挪动，总量没有增加。

> 中国用户平均装有约29个应用，每天花在手机上的时间接近八小时。增长的重心，已经从拉新转向盘活存量。
> 来源：QuestMobile，2025

与此同时，品牌把更多内容投了进去。

> 2025年，小红书服饰品类投放商业笔记的品牌数量同比增长超过56%，美妆商业笔记的月均点赞量上涨76%。
> 来源：千瓜数据，2026

品牌更多，笔记更多，八小时不变。单篇互动只能下行，哪怕品类的互动总量在涨。你的单篇数字可能恰恰在品类最景气的一年里下跌。

解法乏味：每月把互动总量与单篇互动并列进报表。总量在涨而单篇在跌，说明你赢了，只是看板把结论写反了。

微博是那张表里的例外，值得单拎出来。它去年丢了日均使用时长，常见的应对是加大发布量。方向反了。

微博付费的是“参与正在发生的事”。脱离热搜，一条微博近似在空房间里说话；进了热搜，它的扩散速度在国内仍无对手。

## 评论区属于生产环节，不属于审核环节

诊断到此为止。往下是我们真正会动手的地方，起点恰在多数品牌不看的一处。

国际品牌习惯把评论划归客服：一周看两次，删掉不礼貌的，投诉严重就回一条。在中国的平台上，这等于把最强的杠杆闲置。

> 抖音的内容标签分三层构建：来自视频本身的核心标签占50%权重，来自用户搜索与评论区的辅助标签占30%，预测标签占20%。
> 来源：极致了数据，2025

抖音把视频推给谁，将近三分之一由观众打在下面的字决定。把这段对话空着，平台就用碰巧出现的内容替你贴标签。

落到一个正常账号上，动作是这些：

- 两小时内回复。在小红书，这个窗口对把笔记送进下一个流量池权重最高。
- 提两个字答不完的问题。短回复计分，长而具体的回复计分更重。
- 把想被搜到的词种进评论。卖油皮精华，“油皮”二字要出现在评论里，而不只是文案里。
- 把带关键产品信息的评论置顶，省得同一句话写四十遍。
- 把评论当调研读。反复出现的问题，就是接下来三条内容的选题。

我们在上海和香港的团队，每个发布日都守在这段窗口里，用中文回评论。一个正常账号，单篇约二十到四十分钟，多数落在前两小时。这活枯燥，没人抢着做；可按小时折算，它是这些平台上最便宜的一笔效果提升。

## 每个平台该考核什么

围着一个下跌的数字推翻内容方案之前，先确认这个数字和平台奖励的东西对得上。多数情况下对不上：正准备推倒的那套方案，其实一直在起作用。

| 平台         | 停止考核        | 开始考核                      |
| ------------ | ------------- | --------------------------- |
| 微信         | 只看打开率      | 转发、在看、企业微信加好友       |
| 小红书        | 单篇点赞数      | 长评论、来自搜索的阅读          |
| 抖音         | 首日播放量      | 三秒留存、第7到15天的表现       |
| 微博         | 粉丝数         | 话题参与量、热搜期间的转发       |

最后一列在微信上分量最重。转发、在看、企业微信加好友，都能扛过算法下季度改主意，因为每一个动作都把一个人往你自己的用户资产上推近一步，而不是继续租流量。

[企业微信](/zh/insights/what-is-wecom/)那一篇讲清了这层私域怎么跑，以及公域越贵、这些数字为什么越稳。

接下来要解决的是拿什么内容去填，交给[中国内容配比](/zh/insights/content-mix-china/)那一篇。

以上没有一条要求你多产内容，只要求把已经在发的东西，放进对的那一列考核。

同样出于这个区别，我们的[价格](/zh/pricing/)页面写明固定范围与固定价格，在你开口联系之前就已公开。

按产出量收费的代理商，天然有动力在量已经失效的那一年继续卖你量。固定范围把这个动机掐掉。这件事比字面上重要，因为正确答案往往是少发一些，把每一条做得更重。
