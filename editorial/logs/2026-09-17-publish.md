## Locale work, in required order

FR, then ZH, then DE, then ES. Each locale got the two-step process from
`TRANSLATION_GUIDE.md` section 4: a humanized translation, then the mandatory
in-language native rewrite worked from the target-language draft rather than
from the English, plus further editorial passes on headings, metadata and
citation prose. No locale stopped at step 1.

| Locale | Register and conventions applied |
|---|---|
| FR | Le Monde register, `Source :` with NBSP before `:` `;` `?` and inside guillemets, curly apostrophes, French number formatting |
| ZH | 财经 / 36氪 register, `来源：`, full-width punctuation throughout, 万 and 亿 units, half-width numerals and URLs |
| DE | FAZ / Handelsblatt register, consistent Sie, `Quelle:`, low-9 quotation marks, `ß` and umlauts complete |
| ES | El País register, peninsular Spanish, consistent usted, `Fuente:`, guillemets, mandatory `¿` |

Two consistency decisions, both taken from the existing corpus rather than from
preference. DE percentages use `77 %` and not `77 Prozent`, because the
fourteen existing DE articles do. FR keeps the non-breaking space before
`:` `;` `?` per `TRANSLATION_GUIDE.md` section 7, the same choice the
2026-09-15 file made; the open question for Cyril about the older FR corpus,
which uses a plain space, is unchanged.
